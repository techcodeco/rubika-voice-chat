# Rubika Voice Documentation

This folder contains the static documentation website for **Rubika Voice 1.5.3**.

- `index.html`: Persian API documentation, examples, and bilingual creator attribution.
- `styles.css`: responsive layout, syntax-highlight presentation, copy-button styles, author-credit styling, and active sidebar navigation.
- `favicon.svg`, `favicon.ico`, and PNG variants: the Rubika-colour microphone favicon for browsers and mobile home-screen icons.
- `site.webmanifest`: PWA icon and theme metadata.

## Publish with GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, choose the default branch, and set the folder to `/docs`. The code samples use Highlight.js and include copy buttons. The sidebar marks the section currently in view with a yellow accent.

Keep this folder synchronized with the public API, audio recorder, audio player, and test suite whenever APIs or documented behavior change.
